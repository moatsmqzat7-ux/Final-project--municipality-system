# نظام مخازن البلدية

نظام ويب لإدارة ومتابعة مخازن البلدية والمواد — بدل التسجيل اليدوي.



## الوظائف

- 📦 **المواد:** اسم، كود، تصنيف، وحدة، كمية حالية، حد أدنى، حالة (متوفرة/منخفضة/نفدت)
- 🏬 **المخازن:** إضافة مخازن + الموقع + عرض المواد في كل مخزن
- ➕ **إدخال:** مورد/جهة موردة + كمية + تاريخ → تحديث تلقائي للمخزون
- ➖ **إخراج:** جهة/قسم مستفيد + كمية + تاريخ → خصم تلقائي (مع منع الصرف فوق المتاح)
- 📊 **التقارير:** الجرد الحالي، النواقص، سجل الحركات، حركة مادة خلال فترة + طباعة
- 👥 **الصلاحيات:** مدير (كل شيء + حذف + مستخدمون) / موظف مخزن (تشغيل يومي فقط)
